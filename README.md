# adaptexts — dataset browser

This repository hosts an illustrating [web page](https://al-noori.github.io/adaptexts-web/) for the [adaptexts](https://codeberg.org/thille/adaptexts) Python package.

The site gives a browsable overview of the formal contexts available through the package's adapter architecture, along with dataset metrics, source metadata, and usage snippets.
